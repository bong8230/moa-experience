공고를 불러오는 중이에요.

이 탭의 공고는 자동으로 모으지 않아요. 사이트 정책상 직접 열어서 확인해야 하는 곳이에요. 신청한 공고는 찜에 직접 추가하면 마감일을 함께 챙길 수 있어요.

무신사 체험단

무신사 앱이나 웹에서 공고를 고르고 바로 응모해요.

무신사는 등록되지 않은 자동 수집 프로그램의 접근을 막고 있어서(robots.txt) 목록을 가져오지 않아요. 엔조잇은 무신사 공고를 함께 보여 주는 외부 집계 사이트인데, 이용약관이 자동 수집을 금지해서 링크만 연결해요.

카카오톡 선물하기 체험단

카카오톡 앱에서 선물하기 → 체험단 탭으로 들어가 신청해요. 당첨 여부는 알림톡으로 와요.

웹에 공개된 목록이 없고 앱 안에서만 볼 수 있어서 가져오지 않아요.

쿠팡 체험단

신청하는 방식이 아니에요. 쿠팡이 고른 회원에게 앱 알림, 문자, 이메일로 초대가 와요.

공개 모집 목록이 없어서 가져올 공고가 없어요. 초대를 받으면 찜에 추가해 주문·리뷰 기한을 챙기세요.

초대 문자는 1577-7011에서만 와요. 다른 번호나 외부 링크로 온 초대는 사칭일 수 있어요.

닉네임 정하기

모아체험에서 내 이름으로 보여요. 2~20자, 다른 사람과 같아도 괜찮아요.

찜에 직접 추가

자동으로 모으지 않는 공고를 내 찜 목록에 기록해요. 공고 내용은 가져오지 않아요.
